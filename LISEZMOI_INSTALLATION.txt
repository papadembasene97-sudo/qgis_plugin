┌──────────────────────────────────────────────────────────────────┐
│ ÉTAPE 1 : TÉLÉCHARGER LE PLUGIN                                 │
└──────────────────────────────────────────────────────────────────┘

Lien direct :
https://github.com/papadembasene97-sudo/qgis_plugin/releases/download/v1.1.1/cheminer_indus.zip

Taille : 5.4 MB


┌──────────────────────────────────────────────────────────────────┐
│ ÉTAPE 2 : INSTALLER DANS QGIS                                   │
└──────────────────────────────────────────────────────────────────┘

1. Ouvrir QGIS
2. Menu "Extensions" → "Installer/Gérer les extensions"
3. Cliquer sur l'onglet "Installer depuis un ZIP"
4. Cliquer sur "..." et sélectionner le fichier téléchargé
5. Cliquer sur "Installer le plugin"

✅ Message attendu : "Installation réussie : TRACK-EAU-POLL v1.1.1"


┌──────────────────────────────────────────────────────────────────┐
│ ÉTAPE 3 : VÉRIFIER L'INSTALLATION                               │
└──────────────────────────────────────────────────────────────────┘

Le dock "TRACK-EAU-POLL" doit apparaître dans QGIS.

Si le dock n'apparaît pas :
→ Menu "Extensions" → "TRACK-EAU-POLL" → Cliquer pour afficher


┌──────────────────────────────────────────────────────────────────┐
│ ❌ PROBLÈME D'INSTALLATION ?                                     │
└──────────────────────────────────────────────────────────────────┘

Si vous voyez ce message :
"Disparition de l'extension... Le répertoire ... n'a pas été trouvé"

→ Vous avez téléchargé une ANCIENNE version du ZIP !

SOLUTION :
1. Désinstaller le plugin actuel
2. Télécharger À NOUVEAU le ZIP depuis le lien ci-dessus
3. Réinstaller


┌──────────────────────────────────────────────────────────────────┐
│ 🚀 MÉTHODE ALTERNATIVE : DÉPÔT PERSONNALISÉ                     │
└──────────────────────────────────────────────────────────────────┘

Pour recevoir les mises à jour automatiquement :

1. QGIS → Extensions → Installer/Gérer les extensions
2. Onglet "Paramètres"
3. Section "Dépôts de plugins" → Cliquer sur "Ajouter..."
4. Remplir :
   Nom : TRACK-EAU-POLL
   URL : https://raw.githubusercontent.com/papadembasene97-sudo/qgis_plugin/main/plugins.xml
5. Cliquer sur "OK"
6. Onglet "Tous" → Chercher "TRACK-EAU-POLL"
7. Cliquer sur "Installer le plugin"
